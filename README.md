# Chatbot de Gestão v2

Arquitetura modular com consulta documental, cache em memória, limite de frequência, integração com Telegram, respostas estruturadas, indicação de evidência e testes automáticos.

## Importante
Mantenha o arquivo `instrucoes.rtf` existente na raiz do repositório. Não publique chaves.

## Testes
`pip install -r requirements-dev.txt` e `pytest`.

## Variável adicional
Cadastre `TELEGRAM_USERNAME` no Render apenas com o nome do bot, sem `@`.

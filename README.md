# Chatbot de Gestão

Protótipo desenvolvido para um trabalho de iniciação científica sobre Processamento de Linguagem Natural aplicado à gestão.

O sistema responde perguntas com base no conteúdo do arquivo `instrucoes.rtf`, utilizando FastAPI e a API Gemini.

## Tecnologias

- Python
- FastAPI
- HTML, CSS e JavaScript
- API Gemini
- GitHub
- Render

## Modelo utilizado

`gemini-3.6-flash`

## Limitação

O protótipo foi avaliado com um documento simulado e um conjunto delimitado de perguntas. Os resultados não devem ser generalizados para documentos e situações que não tenham sido testados.
